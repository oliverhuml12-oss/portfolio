# Oliver Huml — CV

Static one-page CV. Plain HTML + CSS, no build step.

## Files
- `index.html` — all content
- `styles.css` — styling; colours and spacing are CSS variables at the top. Breakpoints: 900px (tablet), 640px (phone). Print / Save as PDF rules at the bottom (A4).
- `images/portrait.webp` — photo (transparent background)
- `images/og-image.jpg` — link preview image (1200×630)
- `favicon.svg`

## Deploy
1. Create a new GitHub repository and upload the contents of this folder (index.html must be at the root).
2. On vercel.com: Add New → Project → import the repo → Framework Preset: **Other** → Deploy. No build command, no output directory.

## Edit
Change text directly in `index.html`. Every push to GitHub redeploys automatically.

## PDF
Open the site in Chrome → Print → Save as PDF, A4, margins: None, "Background graphics" on.
